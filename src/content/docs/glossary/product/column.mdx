## 컬럼(슬롯)이란?
    <Figure src={Image1} caption={"일반적인 머신기 형태"} />
`컬럼(슬롯)`은 머신기 내부에서 상품이 저장되어 있는 **물리적 위치 단위**를 의미해요.

자판기, 냉장고형 판매기, 인형뽑기 등 대부분의 머신기는
상품을 컬럼(또는 슬롯) 번호 기준으로 관리해요.

즉, 머신기는
“어떤 상품이 판매되었는지”가 아니라
**“몇 번 컬럼에서 판매되었는지”를 기준으로 동작**해요.

</Frame>

<Frame>

## 컬럼과 거래 데이터의 관계

거래가 발생하면 머신기에서는 일반적으로

- 결제 금액
- 컬럼번호

만 서버로 전송해요.

따라서 전산에서는
이 컬럼번호를 기준으로
웹에 등록된 웹 상품과 매칭하여
거래내역에 상품명을 표시해요.

즉,

컬럼번호 → 상품코드 → 상품명

구조를 통해 사람이 이해할 수 있는 형태로 변환돼요.

</Frame>

<Frame>

## 컬럼과 웹 상품 매칭

전산에서는 단말기 또는 머신기별로
컬럼마다 판매 항목을 등록할 수 있어요.

예를 들어,

- 컬럼 01 → A 음료
- 컬럼 02 → B 음료
- 컬럼 03 → C 상품

처럼 설정돼요.

이 매칭 정보는
거래내역 표시와 매출 분석의 기준이 돼요.

</Frame>

<Frame>

## 스마트 자판기의 경우

일부 스마트 자판기는
컬럼번호뿐 아니라 **상품코드까지 함께 전송**할 수 있어요.

이 경우에는 컬럼 매칭이 아닌
전송된 상품코드를 기준으로 거래가 저장돼요.

하지만 대부분의 머신기는
여전히 컬럼 기반 구조를 사용해요.

</Frame>

<Frame>

## 운영 시 주의사항

현장에서 컬럼에 진열된 상품을 변경했는데
웹의 컬럼-상품 매칭을 수정하지 않으면
실제 판매 상품과 웹에 표시되는 상품이 달라질 수 있어요.

또한,

- 컬럼 번호 설정 오류
- 머신기 설정 변경
- 펌웨어 업데이트로 인한 번호 체계 변경

등으로 인해
거래 데이터 불일치가 발생할 수 있어요.

따라서 컬럼 설정은
현장 구성과 전산 설정이 항상 일치하도록 관리해야 해요.

</Frame>

<Frame>

## 정리

- 컬럼(슬롯)은 머신기 내부의 물리적 상품 위치 단위
- 대부분의 거래는 컬럼번호 기준으로 발생
- 전산에서는 컬럼 ↔ 웹 상품 매칭을 통해 거래내역 표시
- 현장 상품 변경 시 컬럼 매칭도 함께 수정 필요

</Frame>
