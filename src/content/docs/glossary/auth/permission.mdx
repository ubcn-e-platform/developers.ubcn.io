## 권한이란?

`권한`은 계정이
전산 구조 내에서 어디까지 조회하고
어떤 항목을 수정·관리할 수 있는지를 결정하는 기준이에요.

권한은 체인 > 회사 > 상점 > 그룹 > 단말기
구조를 기반으로 설정돼요.

</Frame>

<Frame>

## 권한 구조의 기본 원칙

1. 상위 계정은 하위 구조에 대해 간섭 가능
2. 하위 계정은 상위 구조에 접근 불가
3. 체인관리자는 조회 전용
4. 회사대표자가 회사 단위 최고 권한

</Frame>

<Frame>

## 조회 권한

조회 권한은 데이터 확인 범위를 의미해요.

- 체인관리자 → 체인 전체 조회
- 회사대표자 → 회사 전체 조회
- 상점관리자 → 해당 상점 조회
- 그룹관리자 → 해당 그룹 조회
- 운영자 → 지정 단말기 조회

</Frame>

<Frame>

## 관리 권한

관리 권한은 수정·등록 가능 여부를 의미해요.

### ✔ 회사대표자
- 웹 상품 등록·수정
- 상점·그룹 구조 관리
- 하위 계정 관리

### ✔ 상점관리자
- 상점 하위 구조 관리
- 웹 상품 조회만 가능

### ✔ 그룹관리자
- 그룹 하위 단말기 관리
- 상위 구조 수정 불가

### ✔ 운영자
- 관리 권한 없음 (조회 중심)

### ✔ 체인관리자
- 조회만 가능
- 수정 권한 없음

</Frame>

<Frame>

## 정산 정보 접근

정산 정보는 상점 단위로 집계돼요.

- 회사대표자 → 전체 정산 조회 가능
- 상점관리자 → 해당 상점 정산 조회 가능
- 그룹관리자/운영자 → 제한적 또는 조회 불가
- 체인관리자 → 조회 가능 (수정 불가)

</Frame>

<Frame>

## 정리

- 권한은 구조 기반 접근 통제 체계
- 체인관리자는 조회 전용
- 회사대표자가 실질적 최고 권한
- 웹 상품 수정은 회사대표자만 가능
- 단말기 접근 최소 단위는 운영자

</Frame>
