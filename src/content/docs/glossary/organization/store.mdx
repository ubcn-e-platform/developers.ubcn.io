## 상점이란?

`상점`은 **정산 단위로 구분되는 운영 구조 단위**예요.

전산 구조상 상점은 단순한 물리적 상점이 아니라,
**정산 통장(가맹점번호) 기준으로 분리되는 관리 단위**를 의미해요.

즉, 상점은
"정산을 어떻게 받을 것인가"에 따라 생성되는 구조예요.

</Frame>

<Frame>

## 전산 구조 내 위치

유비씨엔 전산 구조는 다음과 같아요.

체인 > 사업자 > 상점 > 그룹 > 단말기

- **체인**: 여러 사업자의 집합
- **사업자**: 하나의 사업자 (사업자등록번호 단위)
- **상점**: 정산 통장 및 가맹점번호 기준 관리 단위
- **그룹**: 상점 하위 단말기들의 집합
- **단말기**: 실제 결제가 발생하는 장치

</Frame>

<Frame>

## 사업자와 상점의 차이

- **사업자 = 사업자**
  하나의 사업자등록번호를 가진 계약 주체예요.

- **상점 = 정산 단위**
  동일한 사업자 내에서도 정산 통장이 여러 개라면
  상점을 여러 개 생성하게 돼요.

즉,
사업자는 하나지만
정산 통장이 여러 개라면 상점도 여러 개가 될 수 있어요.

</Frame>

<Frame>

## 상점이 생성되는 기준

상점은 다음과 같은 경우 분리돼요.

- 매입사 가맹점번호가 여러 개인 경우
- 정산 통장을 분리해야 하는 경우
- 매입사와의 계약 구조상 정산 주체가 분리된 경우

정산 통장은
가맹 시점에 **가맹점과 매입사 사이 계약에 의해 결정**돼요.

유비씨엔은 해당 계약 구조에 맞춰
상점을 생성하여 정산을 구분해요.

</Frame>

<Frame>

## 대표 상점 구조

정산 통장을 여러 개로 나눌 필요가 없는 경우에는

- 대표 상점 1개
- 대표 그룹 1개

구조로 운영돼요.

이 경우 모든 단말기는
하나의 상점, 하나의 그룹에 속하게 돼요.

</Frame>

<Frame>

## 상점과 그룹의 관계

`그룹`은 상점 하위에 속한 **단말기들의 집합**이에요.

- 모든 단말기는 반드시 하나의 그룹에 속해요.
- 모든 그룹은 반드시 하나의 상점에 속해요.

그룹은 운영·관리 목적의 구조이며
정산의 주체는 아니에요.

</Frame>

<Frame>

## 상점과 정산의 관계

승인 → 구매 → 마감 → 매입 → 정산

이 모든 과정은
최종적으로 **상점 단위로 집계**돼요.

정산 대금 역시
상점에 연결된 정산 통장 기준으로 입금돼요.

</Frame>

<Frame>

## 핵심 정리

- 체인: 여러 사업자의 집합
- 사업자: 사업자(사업자등록번호)
- 상점: 정산 통장(가맹점번호) 기준 분리 단위
- 그룹: 상점 하위 단말기 집합
- 모든 단말기는 반드시 그룹과 상점에 소속
- 정산 통장은 가맹점과 매입사 계약으로 결정됨

</Frame>
