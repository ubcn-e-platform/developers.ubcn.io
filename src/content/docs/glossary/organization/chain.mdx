## 체인이란?

`체인`은 **여러 사업자(사업자)의 집합 구조**를 의미해요.

브랜드, 본사, 프랜차이즈 구조 등
여러 사업자를 하나의 상위 조직으로 묶을 때 사용돼요.

</Frame>

<Frame>

## 체인의 위치

전산 구조는 다음과 같아요.

체인 > 사업자 > 상점 > 그룹 > 단말기

체인은 사업자들의 상위 개념이며,
정산의 직접적인 주체는 아니에요.

</Frame>

<Frame>

## 체인의 역할

체인은 다음과 같은 목적을 위해 사용돼요.

- 여러 사업자의 매출 통합 조회
- 브랜드 단위 관리
- 운영 정책 통일
- 계정 권한 통합 관리

정산은 사업자/상점 단위로 이루어지며,
체인은 관리·조회 목적의 상위 구조예요.

</Frame>

<Frame>

## 체인 생성 기준

체인은 일반적으로
유비씨엔과의 별도 계약 또는
본사-지점 구조가 존재할 경우에만 생성돼요.

일반 가맹점은 체인을 생성하지 않아요.

</Frame>

<Frame>

## 정리

- 체인은 여러 사업자의 집합
- 정산 주체는 아님
- 브랜드 또는 본사 구조에서 사용
- 상위 통합 관리 구조

</Frame>
