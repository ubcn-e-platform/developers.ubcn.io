## 기타결제란?

`기타결제`는 카드·현금·간편결제 외에
**유비씨엔 자체적으로 제공하는 결제 수단**을 의미해요.

일반 카드망(PG/VAN)을 통하지 않고,
내부 정책과 계약 조건에 따라 사용되는 결제 방식이에요.

기타결제는 다음 3가지 유형으로 구성돼요.

- 쿠폰
- 복지카드
- 멤버십 포인트

</Frame>

<Frame>

## 1️⃣ 쿠폰

`쿠폰`은 **권면가액(설정 금액) 범위 내에서만 사용 가능한 결제 수단**이에요.

### ✔ 특징

- 권면가액 초과 사용 불가
- 금액 내에서만 차감 가능
- 1회권 / 다회권 구조

### ✔ 유형

- **1회권**
  1회 사용 후 소멸

- **다회권**
  정해진 횟수 또는 한도 내에서 여러 번 사용 가능

쿠폰은 행사, 프로모션, 교환권 성격으로 주로 사용돼요.

</Frame>

<Frame>

## 2️⃣ 복지카드

`복지카드`는 기업 또는 기관에서
임직원 복지 목적으로 사용하는 결제 수단이에요.

정기 충전 방식으로 운영돼요.

### ✔ 충전 주기

- 일 단위
- 월 단위
- 연 단위

### ✔ 사용 방식

회사 설정에 따라 사용 정책이 달라져요.

- 잔여 금액까지만 사용 가능
- 잔여액 초과 사용 허용

초과 사용이 허용되는 경우,
초과 금액은 회사별 내부 정산 정책에 따라 처리돼요.

잔여액 제한 모드일 경우에는
충전된 금액 내에서만 사용 가능해요.

</Frame>

<Frame>

## 3️⃣ 멤버십 포인트

`멤버십 포인트`는
회원 계정에 적립된 포인트를 차감하여 사용하는 결제 방식이에요.

### ✔ 특징

- 반드시 잔여 포인트 내에서만 사용 가능
- 초과 사용 불가
- 차감형 구조

포인트는 적립 → 사용 → 차감 구조로 운영돼요.

</Frame>

<Frame>

## 기타결제의 공통 특징

- 카드사 승인 과정을 거치지 않아요
- 유비씨엔 전산 정책 기준으로 동작해요
- 단말기에서 전처리 조회 후 사용 가능 여부를 판단해요
- 회사 또는 운영 정책에 따라 사용 조건이 달라질 수 있어요

</Frame>

<Frame>

## 정리

- 기타결제는 내부 정책 기반 결제 수단
- 쿠폰은 권면가액 내 사용
- 복지카드는 정기 충전 + 회사 정책 적용
- 멤버십 포인트는 잔액 한도 내 차감 방식

</Frame>
