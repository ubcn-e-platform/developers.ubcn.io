## 계정이란?

`계정`은 유비씨엔 전산에 로그인하여
데이터를 조회하고 관리하기 위한 사용자 단위예요.

계정은 정산의 주체가 아니며,
전산 구조 내에서 접근 가능한 범위를 가지는 관리 주체예요.

</Frame>

<Frame>

## 전산 구조와 계정의 관계

유비씨엔 전산 구조는 다음과 같아요.

체인 > 사업자 > 상점 > 그룹 > 단말기

계정은 이 구조를 기준으로
어디까지 조회·관리할 수 있는지가 결정돼요.

단말기에 대해 접근 가능한 최대 단위는 **사업자대표자**,
최소 단위는 **운영자**예요.

</Frame>

<Frame>

## 계정 유형

계정은 다음과 같이 구분돼요.

### ✔ 체인관리자
- 체인 단위 조회 전용
- 데이터 수정 불가
- 하위 사업자·상점·그룹 조회만 가능

### ✔ 사업자대표자
- 사업자 전체에 대한 최고 권한
- 모든 상점·그룹·단말기 관리 가능
- 하위 계정 관리 가능
- 웹 상품 등록 및 수정 가능

### ✔ 상점관리자
- 특정 상점 단위 관리
- 해당 상점 하위 그룹 및 단말기 관리 가능
- 웹 상품 조회 가능 (등록/수정 불가)

### ✔ 그룹관리자
- 지정된 그룹 및 하위 그룹만 관리
- 상위 구조 접근 불가
- 웹 상품 조회만 가능

### ✔ 운영자
- 지정된 단말기만 조회 가능
- 단말기 담당자 구조
- 수정 권한 없음

</Frame>

<Frame>

## 단말기 접근 범위

단말기 기준 권한 범위는 다음과 같아요.

- 사업자대표자 → 모든 단말기 접근 가능
- 상점관리자 → 해당 상점 단말기 접근
- 그룹관리자 → 지정 그룹 단말기 접근
- 운영자 → 지정된 단말기만 접근

체인관리자는 조회만 가능하며
실제 단말기 설정 변경은 불가해요.

</Frame>

<Frame>

## 웹 상품 관리 권한

`웹 상품`은 사업자 단위 관리 항목이에요.

- 등록·수정 가능: **사업자대표자**
- 조회만 가능: 상점관리자, 그룹관리자, 운영자
- 체인관리자: 조회 전용

웹 상품은 거래 구조와 직결되기 때문에
최상위 관리자인 사업자대표자만 수정 가능해요.

</Frame>

<Frame>

## 정리

- 계정은 전산 접근 주체
- 체인관리자는 조회 전용
- 사업자대표자가 최고 관리 권한
- 하위 권한은 상위에 간섭 가능
- 웹 상품 수정은 사업자대표자만 가능

</Frame>
