## ✔️Payload - 쿠폰 조회하기
발권된 쿠폰의 현재 상태를 조회할 수 있습니다.
<br/>
<strong style={"color: green"}>GET</strong> /`{couponNo}`/type/`{type}`/`{id}`
<Frame>
    ```ts
    //쿠폰 번호로 쿠폰의 현재 상태를 조회합니다.
    const res = await API.get("/{couponNo}/type/{type}/{id}");
    ```
</Frame>
