## 일일 거래내역 조회
<Frame>
    ### Request Schema
    요청에서 필요로 하는 필드는 다음과 같습니다.
    <Table
        headers={[{"title": "필드명"}, {"subTitle": "상세필드명"}, {"notNull": "필수"},
            {"argsType": "타입"}, {"desc": "설명"}, {"etc": "비고"}]}
        bodys={[
            [
                {"title": "date"},
                {"subTitle": "-"},
                {"notNull": "Y"},
                {"argsType": "String"},
                {"desc": "거래일자"},
                {"etc": `일자 규격은 'YYYYMMDD'를 따름.`},
            ],
        ]}>
    </Table>
    ### 호출구문
    ```ts
    const API = axios.create({
            baseURL: `http://api.ubcn.co.kr/api`,
            headers: {
                "Access-Control-Allow-Origin": "*",
                "PER-ID": "{유출금지}",
                "PER-TOKEN": "{유출금지}",
            },
    });

        // post 요청만을 지원합니다.
        // {date}는 "YYYYMMDD" 규격을 따릅니다.
        const res = await API.post("/well/sales/{date}");
        console.log(res.data);

        // 프로세스가 제대로 완료되지 않은 경우 에러 코드가 존재합니다.
        if (res.code != null) {
            return alert(res.decription);
        }
    ```
    <br/>
