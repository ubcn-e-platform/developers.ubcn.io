<Frame>
발생한 매출에 대해 마감된 정보를 조회할 수 있습니다.<br/>
마감내역은 단말기별 `상품별` 또는 `컬럼별`로 집계된 건수·금액을 결제수단별로 제공합니다.<br/>
마감의 종류로는 `수동마감`과 `자동마감`이 존재합니다.

+ 수동마감
    + 머신기 또는 단말기에서 직접 마감을 진행하는 경우
    + 특정 시간에 마감을 진행하는 경우(예: 17:45:00) - (단말기 펌웨어를 통해 제어)
+ 자동마감
    + 시스템에서 자동으로 마감을 진행하는 경우(23:59:59 고정)

<b>마감내역 조회는 `마감일자 기준 조회`와 `24시간 구간 조회` 두 가지 방식을 지원합니다.</b>

- 모든 요청은 헤더에 `company`, `token`이 필요합니다. ([API 시작하기](/api/) 참고)
- `GET`, `POST` 방식을 모두 지원하며, 요청 Body는 사용하지 않습니다.
- 조회 결과가 없는 경우 HTTP 상태코드 `404`와 함께 `closingList` 필드가 제외된 응답이 전달됩니다.
</Frame>

## 마감일자 기준 조회
<Frame>
    <strong style={"color: green"}>GET | POST</strong> /closing/`{closingType}`/`{date}`

    단말기의 마감일자가 요청일자(`date`)인 거래를 집계하여 조회합니다.<br/>
    오늘 날짜로 조회하는 경우, 아직 자동마감(23:59:59)이 진행되지 않았으므로 **수동마감된 거래만** 집계됩니다.<br/>
    취소된 거래는 집계에서 제외됩니다.

    ### Request Schema
    요청에서 필요로 하는 필드는 다음과 같습니다.
    <Table headers={reqHeaders} bodys={[
        reqRow("closingType", "Y", "String", "집계 유형 (Path)", "`product`: 단말기 + 상품별 집계<br/>`column`: 단말기 + 컬럼별 집계"),
        reqRow("date", "Y", "String", "마감일자 (Path)", "`YYYYMMDD` 규격<br/>오늘 이후의 일자는 요청 불가"),
    ]}></Table>

    ### 호출구문
    ```ts
    const API = axios.create({
      baseURL: `http://api.ubcn.co.kr/api`,
      headers: {
        "company": "{company}",
        "token": "{token}",
      },
      // 조회 결과가 없을 때 404가 응답되므로, 404는 정상 응답으로 처리합니다.
      validateStatus: (status) => status < 500,
    });

    // get, post 모두 지원합니다.
    // 예시) 2026년 10월 15일 마감내역을 상품별로 조회
    const res = await API.get("/closing/product/20261015");

    // 예시) 2026년 10월 15일 마감내역을 컬럼별로 조회
    const res2 = await API.get("/closing/column/20261015");

    if (res.status === 200) {
      console.log(res.data.closingList);
    } else if (res.status === 404) {
      console.log("조회된 마감내역이 없습니다.");
    } else {
      // 요청 오류: code(존재하는 경우), message 를 확인합니다.
      console.error(res.data.code, res.data.message);
    }
    ```

## 24시간 구간 조회
<Frame>
    <strong style={"color: green"}>GET | POST</strong> /closing/`{closingType}`/`{date}`/`{time}`

    마감 여부와 관계없이, 요청일자 전일의 `time`부터 요청일자의 `time` 직전까지 **24시간 동안 발생한 거래**를 집계하여 조회합니다.<br/>
    가맹점의 정산 기준 시각이 자정이 아닌 경우(예: 매일 18시 기준)에 사용합니다.

    ### Request Schema
    요청에서 필요로 하는 필드는 다음과 같습니다.
    <Table headers={reqHeaders} bodys={[
        reqRow("closingType", "Y", "String", "집계 유형 (Path)", "`product`: 단말기 + 상품별 집계<br/>`column`: 단말기 + 컬럼별 집계"),
        reqRow("date", "Y", "String", "기준일자 (Path)", "`YYYYMMDD` 규격<br/>오늘 이후의 일자는 요청 불가"),
        reqRow("time", "Y", "String", "기준시간 (Path)", "`HHMISS` 규격 (24시간제)"),
    ]}></Table>

    ### 호출구문
    ```ts
    // get, post 모두 지원합니다.
    // 예시) /20261015/180000 입력 시
    // 2026-10-14 18:00:00 부터 2026-10-15 17:59:59 까지 발생한 거래를 상품별로 집계합니다.
    const res = await API.get("/closing/product/20261015/180000");
    ```

    ### 참고사항
    - 응답의 `closingList.closingDate`에는 요청한 기준일자(`date`)가 전달됩니다.
    - 매월 1일에 호출하는 경우, 전일 데이터는 포함되지 않고 기준일자 `000000`부터 `time` 직전까지의 거래만 집계됩니다.

    <b>※ 응답 규격 및 예시는 상단의 [마감일자 기준 조회]와 동일합니다.</b>
</Frame>

## 집계 데이터 해석 시 참고사항
<Frame>
    - `totCnt`, `totAmt`는 모든 결제수단의 합계입니다. 결제수단별 항목에 포함되지 않는 결제수단(예: 그 외 간편결제)이 있을 수 있으므로, 결제수단별 합계와 일치하지 않을 수 있습니다.
    - `column` 집계 시 컬럼번호가 4자리인 머신기는 앞 2자리가 `colNo`, 뒤 2자리가 `cabNo`로 전달됩니다.
    - `column` 집계는 단말기 + 컬럼 + 상품 단위로 집계되므로, 동일 컬럼에서 판매 상품이 변경된 경우 여러 행으로 나뉘어 전달될 수 있습니다.
    - 응답 필드의 순서는 보장되지 않습니다. 필드명으로 값을 참조해 주세요.
</Frame>

    </Table>

      "message": "closingType이 명확하지 않습니다."
